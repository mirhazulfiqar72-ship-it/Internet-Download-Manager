Questions

Frequently asked.

Quick answers about downloads, updates and installation.

How do I update to a newer version?

Open Help → Check for Updates. When a newer release is available, the app shows an update dialog with a Download update option.

When does the duplicate download dialog appear?

It appears when the same download is already present in the downloader list. If that entry has been removed, downloading it again does not trigger the duplicate dialog.

Can I pause and resume a download?

Yes. Resume support depends on the source server, but supported transfers can be paused and continued later.

Where does the installer come from?

The download button uses the latest published release from this project's GitHub repository.
